# データベースをつなぐ手順（無料）

クラウドセーブ（引き継ぎ）とプレイ情報の収集は、Vercel の関数（`api/`）と Upstash Redis で動きます。
データベースをつなぐまでは、ゲームは「クラウド機能は準備中」と表示し、これまでどおり遊べます。

## 1. Upstash Redis を作って、プロジェクトにつなぐ

1. https://vercel.com にログインし、プロジェクト **magia-tower-f** を開く。
2. 上のタブの **Storage** → **Create Database**（または Browse Marketplace）→ **Upstash for Redis** を選ぶ。
3. プランは **Free** を選ぶ。地域は日本に近いもの（例：Tokyo / Asia Pacific）を選ぶ。
4. 作成後、**Connect Project** で magia-tower-f につなぐ（Production・Preview の両方にチェック）。
   - これで環境変数 `KV_REST_API_URL` と `KV_REST_API_TOKEN` が自動で入ります。

## 2. 集計画面の合言葉を決める

1. magia-tower-f → **Settings** → **Environment Variables** を開く。
2. 名前 `ADMIN_TOKEN`、値に**長くて推測されない文字列**（20文字以上。例：パスワード生成で作ったもの）を入れて保存する。
   - 12文字未満だと、集計画面は開けないようにしてあります。

## 3. 作り直す（再デプロイ）

環境変数は、次のデプロイから効きます。
**Deployments** → いちばん上の行の「…」→ **Redeploy** を押す（または次にプッシュしたとき）。

## 4. 確かめる

- https://magia-tower-f.vercel.app/api/health を開いて `{"ok":true,"db":true}` と出れば接続できています。
- ゲームの「データ管理」で「引き継ぎを設定する」が押せるようになります。
- 集計は https://magia-tower-f.vercel.app/admin.html で、合言葉を入れて見られます。

## 無料枠について

| サービス | 無料枠（目安） | このゲームでの使い方 |
|---|---|---|
| Upstash Redis（Free） | 保存 256MB、月50万コマンド | 1時間遊ぶと約80コマンド。全員合計で月 約6,000時間ぶん |
| Vercel（Hobby） | 関数の呼び出しなどに無料枠 | 1時間遊ぶと約18回 |

- 無料枠を超えると、サーバーがエラーを返し、クラウド保存とプレイ情報の送信が止まります。**ゲーム自体は止まりません**（端末内のセーブで動き続けます）。翌月にまた使えるようになります。
- 使った量は、Vercel の **Usage** と、Upstash のダッシュボードで見られます。
- 有料プランに切り替えない限り、料金はかかりません。

## プライバシーページ

`privacy.html` の「運営者・お問い合わせ」に、公開してよい名前と連絡先（メールアドレスや問い合わせフォームなど）を書いてください。

## 困ったとき

| 症状 | 確かめること |
|---|---|
| `/api/health` が `db:false` | Storage でデータベースが magia-tower-f につながっているか。つないだ後に再デプロイしたか |
| 集計画面で「合言葉が違います」 | `ADMIN_TOKEN` の値と、再デプロイしたか |
| 集計画面で「失敗が多すぎます」 | 1日に20回間違えると、その日はその通信元から開けません。翌日に試す |
| 「無料枠を使い切った」 | Upstash のダッシュボードで使用量を確認。翌月に戻る |
