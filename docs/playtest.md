# テストプレイのお願い（依頼文とチェックリスト）

## 依頼文（そのまま送れます）

> マギア・タワー（ブラウザで遊べるカードゲーム）のテストプレイをお願いします。
> https://magia-tower-f.vercel.app/
>
> - 最初に「プレイ情報を送りますか？」と聞かれたら、「送る」を選んでください（名前などは送られません。詰まりやすい場所の調整に使います）。
> - 説明を読まずに、思うままに遊んでください。最初の **2時間** くらい（ラスボスを倒すところまで）が目安です。
> - 途中で「わからない」「つまらない」「つらい」と感じたところがあったら、そのときの階と一言をメモしてください。
> - 終わったら、下の質問に答えてもらえると助かります。

## 終わった後の質問

1. 最初の10分で、何をすればいいか分かりましたか？　分からなかったことは？
2. 「もうやめよう」と思った瞬間はありましたか？　何階で、なぜ？
3. 数字が大きくなる気持ちよさはありましたか？　いちばん気持ちよかった瞬間は？
4. 基本強化・デッキ強化・商人のうち、使い方が分からなかったものは？
5. オート（AUTO）は使いましたか？　使った理由・使わなかった理由は？
6. ラスボスまで届きましたか？　どのくらいかかりましたか？
7. 画面で見づらかった・押しにくかったところは？（スマホ／PC どちらで遊んだか）
8. 自由に一言

## 観察する点（見ている側のチェックリスト）

- [ ] 「塔に挑む」から最初の戦闘まで、迷わず進めたか
- [ ] 最初の敗北の後、基本強化（起点）に気づいたか
- [ ] 手札のカードの選び方に迷っていないか（バフ → 攻撃の順に気づくか）
- [ ] 商人の画面で何を買うか迷っていないか
- [ ] 10階（中ボス）・50階・91〜99階で止まっている時間
- [ ] 同じ階で3回以上続けて負けていないか
- [ ] 倍率の内訳（戦闘画面の「倍率」）に気づいたか
- [ ] オートに気づいたか、いつ使い始めたか
- [ ] 転生（ラスボス後）の意味が伝わったか

## 集計の見方

集計画面 https://magia-tower-f.vercel.app/admin.html （合言葉が必要。`docs/server-setup.md`）で、次の数字を見ます。

| 見る数字 | 目安 | 外れていたら |
|---|---|---|
| ラスボス初撃破までのプレイ時間（中央値） | 1〜1.5時間 | 長すぎれば序盤の敵HPか強化の値段を下げる |
| 負けた階（多い順） | 特定の階に集中していない | 集中している階の前後を調整する |
| 1回の挑戦の秒数 | 数分 | 長すぎればテンポを見直す |
| オート中心のラン | — | 高すぎれば、手で遊ぶ理由が薄い |
| 苦難の挑戦・達成・放棄 | 放棄が多すぎない | 放棄が多い苦難は重すぎる |
