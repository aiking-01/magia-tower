ダメージ表記のグリフ画像について
================================

ここにある d0.png〜d9.png / comma.png / dot.png / minus.png / plus.png / E.png /
A.png / C.png / I.png / L.png / R.png / T.png は、ゆうたONEフォント
「Y1StadiumSlab-Block」(https://... 170K-AnnivPack-FREE200 に同梱) から、
ダメージ表記に実際に使う文字（数字0-9, , . - + E と "CRITICAL" のスペル
A C I L R T）だけをラスタライズ（画像化）したものです。
（以前は同シリーズの「Y1StadiumSlab-Outline」から作っていたが、Block版に差し替え済み。）

なぜフォントファイル(.otf)を直接Webフォントとして埋め込まなかったか
--------------------------------------------------------------
ゆうたONEフォント利用規約（配布readme.txt内のGoogleドキュメントリンク先）に
以下の明記があるため:

  「ゲームやアプリ等、フォントデータをシステムに組み込む場合は
    第三者が吸い出せない形での利用をお願いします。」
  「Q. ビットマップフォントにして利用可能ですか？
    A. 可能です。が、利用時に第三者が吸い出せてしまったり(中略)
       規約違反です。」

@font-face でフォントファイルそのものをWeb配信すると、ブラウザの開発者ツール
やキャッシュから元の.otfファイルがそのまま（再利用可能な状態で）誰でも
ダウンロードできてしまい、上記の規約に抵触する。

そのため、実際に使う文字だけを画像として書き出し、CSSの mask-image で
currentColor に着色して表示する方式にした（game.js の appendDmgChars /
style.css の .dmg-char を参照）。これらのPNGから元のフォントファイル
(インストールして任意の文字を打てる状態)を再構成することはできない。

フォントファイル自体はこのリポジトリのどこにもコミットしていない。

再生成する場合
--------------
文字を追加・変更したくなったら、同じフォントファイルを使ってラスタライズを
やり直す必要がある。手順はこのコミットの説明を参照。
